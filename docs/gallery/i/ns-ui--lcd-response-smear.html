LCD Response Smear

An ambient panel-diagnostics status card whose canvas strip simulates LCD pixel response time compensation: a sweeping fill boundary crosses a row of simulated cells, each newly-lit cell overshooting its target luminance before settling and each newly-darkened cell undershooting (lagging) before catching up, the asymmetric rise/fall overdrive behavior real display reviews call the "inverse ghost".

Rendered on the shadcn default neutral palette with harness-generated props.
