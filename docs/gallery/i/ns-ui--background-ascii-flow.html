Background ASCII Flow

An ambient ASCII flow-field background: a fixed set of tracer particles ride a time-evolving 2D curl-noise velocity field, each glyph's direction ('-', '|', '/', '\\') and trail alpha encoding its heading and speed, with the pointer stirring a local swirl instead of painting or repelling.

Rendered on the shadcn default neutral palette with harness-generated props.
