The fail count is a floor, not a measurement. Two harness defects inflate it, both fixed for the next run but not re-run here. To isolate a failing item the runner deletes its source — Next type-checks the whole project, so a broken file keeps failing after its route is gone — and when that source was shared with sibling items, the siblings failed on a missing import. 262 failures name @/components and 308 name a relative path; those are the cascade, not defects. And one missing peer dep poisons a whole registry: @magicui reports 241 failures, 234 of which are a single undeclared @radix-ui/react-accordion. PASS is reliable. FAIL means "did not build in this harness", not "broken".
