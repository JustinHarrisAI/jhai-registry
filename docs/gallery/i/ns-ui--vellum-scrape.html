Vellum Scrape

A version-history rail styled as scraping vellum: dragging a vertical depth slider reveals each paragraph's overwritten text exactly where it lived, in real selectable DOM, with a per-run restore control to re-ink an old passage as the document's true content.

Rendered on the shadcn default neutral palette with harness-generated props.
