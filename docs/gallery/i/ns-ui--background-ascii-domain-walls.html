Background ASCII Domain Walls

An ambient ASCII background running a real Ising model just below its critical temperature and inking only the DOMAIN WALLS (the boundaries between up and down spin regions), so a slowly reorganising network of rough hairlines sits on empty ground, with the pointer applying a local magnetic field that clears walls out of its own neighbourhood.

Rendered on the shadcn default neutral palette with harness-generated props.
