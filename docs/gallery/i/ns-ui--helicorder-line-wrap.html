Helicorder Line Wrap

An ambient status widget shaped like a seismograph helicorder drum: a pen traces one line at a time and steps down to a fresh line the instant it runs off the right margin, so the record grows as a stack of offset traces rather than one continuous scroll.

Rendered on the shadcn default neutral palette with harness-generated props.
