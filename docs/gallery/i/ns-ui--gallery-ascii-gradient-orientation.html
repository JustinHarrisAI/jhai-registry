Gallery ASCII Gradient Orientation

A gallery grid where each tile runs its own procedural 3-octave value-noise field and a 3x3 Sobel operator selects glyphs by the field's own gradient ANGLE, bucketed into '-', '/', '|', '\\', keeping only the adaptively top-12%-by-magnitude cells each frame so the field reads as a moving edge sketch.

Rendered on the shadcn default neutral palette with harness-generated props.
